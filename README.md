# One Word for Your Wi-Fi

One word describing my Wi-Fi, written for the make.fun bounty
"One Word for Your Wi-Fi".

The word is "gaslighting". The network insists it is connected —
full bars, strong signal, everything fine — while nothing loads, and
somehow it is always your fault for standing in the wrong room. It
is the most honest word for a network that denies its own failure.

## Run

```sh
python3 main.py
```

This checks the word (one word, 1–20 characters) and writes it to
`/output/entry.txt`.

This entry is on make.fun.
