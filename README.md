# The Moon Finally Answers Back

One line in the voice of the Moon, written for the make.fun bounty
"The Moon Finally Answers Back".

After four billion years of wishes, howls and 3 a.m. promises, the
Moon finally answers — and its answer is a refusal to be what
everyone staring up at it wants it to be. It is a rock, not a
therapist. The comeback lands in one read: the setup is the Moon's
endless patience, the punch is the job description it hands back.

## Run

```sh
python3 main.py
```

This checks the line (one line, 1–240 characters, not only whitespace)
and writes it to `/output/entry.txt`.
